# ProjetJavaXO

A Java client-server Tic-Tac-Toe (XO) game built with sockets, two players connect to a socket server and play against each other in real time.

Built as an S5 mini-project at ENS Tétouan, covering Java sockets, a custom Swing UI, and UML modeling (use case, sequence, class diagrams), co-authored with Hamza Elbagar.

## Stack
Java, Sockets, Swing
